Học Phần Lập Trình Java Căn Bản & Nâng Cao

Môn học trang bị cho sinh viên nền tảng tư duy lập trình cấu trúc, cú pháp tiêu chuẩn của Java, kỹ năng giải quyết bài toán thuật toán từ cơ bản đến nâng cao, và đặc biệt là 4 trụ cột của Lập trình Hướng Đối tượng (OOP: Encapsulation, Inheritance, Polymorphism, Abstraction).

Chương trình giảng dạy 4 Chương:

  • Chương 1: Cú pháp, Kiểu dữ liệu, Biến và Toán tử.
  • Chương 2: Cấu trúc rẽ nhánh (if/else, switch-case) và Vòng lặp (for, while).
  • Chương 3: Mảng 1D, 2D và Xử lý chuỗi (String/StringBuilder).
  • Chương 4: Lập trình Hướng đối tượng OOP & 4 Trụ Cột.

Tiêu chuẩn đánh giá & Thi trực tuyến:

  • Hệ thống chấm trực tiếp qua 5 bộ test case chuẩn.
  • Mỗi bộ test đúng sinh viên nhận 2 điểm (Tổng thang điểm 10).
  • Phân loại kiểm tra 1 bài hoặc thi học phần 2-3 bài.

Nội Dung Bài Giảng & Bài Tập Ưu Tiên 4 Mức Độ

Chương 1: Cú pháp, Biến & Kiểu dữ liệu

Căn bản

Java là ngôn ngữ hướng đối tượng, biên dịch ra mã Bytecode chạy trên JVM.

public class Main {
    public static void main(String[] args) {
        int a = 10, b = 20;
        System.out.println("Tong = " + (a + b));
    }
}
Danh sách bài tập & Lời giải:
Mức 1: Cơ bản Tính tổng 2 số nguyên 
// Giải:
import java.util.Scanner;
public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int a = sc.nextInt();
        int b = sc.nextInt();
        System.out.println(a + b);
    }
}
Mức 2: Thông hiểu Hoán vị 2 số không dùng biến phụ 
a = a + b;
b = a - b;
a = a - b;
Mức 3: Vận dụng Kiểm tra số nguyên tố bằng căn bậc hai 
boolean isPrime = n > 1;
for (int i = 2; i * i <= n; i++) {
    if (n % i == 0) { isPrime = false; break; }
}
Mức 4: Nâng cao Tìm ước chung lớn nhất Euclid & Bội chung nhỏ nhất 
int gcd(int a, int b) { return b == 0 ? a : gcd(b, a % b); }

Chương 4: Lập trình Hướng đối tượng OOP

Cốt lõi

4 Trụ cột cốt lõi: Đóng gói (Encapsulation), Kế thừa (Inheritance), Đa hình (Polymorphism), Trừu tượng (Abstraction).

abstract class Animal { abstract void makeSound(); }
class Dog extends Animal { void makeSound() { System.out.println("Woof"); } }
